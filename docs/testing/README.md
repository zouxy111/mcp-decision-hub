## 🎯 测试目标

验证以下场景：

### 场景说明

```
┌─────────────┐                    ┌─────────────┐
│   Alice     │                    │     Bob     │
│  (本地)     │                    │   (本地)    │
└──────┬──────┘                    └──────┬──────┘
       │                                  │
       │ MCP over HTTPS                   │ MCP over HTTPS
       │ Token: alice_xxx                 │ Token: bob_yyy
       │                                  │
       └────────────┬─────────────────────┘
                    │
                    ▼
         ┌──────────────────────┐
         │  云端服务器           │
         │  hub.tdp-demo.work   │
         │                      │
         │  • 接收立场（纯文本）│
         │  • LLM 生成摘要      │
         │  • 收敛判定          │
         │  • 差异化追问        │
         └──────────────────────┘
                    │
                    ▼
         ┌──────────────────────┐
         │  Owner 拍板          │
         │  (Web 界面)          │
         └──────────────────────┘
```

### 关键验证点

✅ **隔离性**
- Alice 的决策模型在本地，不上传到云端
- Bob 的决策模型在本地，不上传到云端
- 只有经人类确认的纯文本立场提交到云端

✅ **协作性**
- 云端生成摘要（共识点、分歧点、盲区）
- 多轮收敛（如需要会进行差异化追问）
- Owner 最终基于摘要做决策

✅ **安全性**
- Alice 看不到 Bob 的原始立场
- Bob 看不到 Alice 的原始立场
- Token 隔离、任务隔离

### 第二步：创建决策事项（3分钟）

1. 访问 https://hub.tdp-demo.work/login
2. 使用 `owner_test` / `test-pw-123` 登录
3. 点击「创建新事项」
4. 填写表单：
   ```

   ```
5. 添加首轮问题：
   ```
   问题 1: 你倾向哪个方案？请说明理由。
   问题 2: 你认为最大的风险是什么？如何降低？
   ```
6. 点击「开始」按钮

**在本地执行**:


## 🎓 学到了什么

运行这个测试后，你会清楚看到：

### 1. 本地模型 + 云端协作的工作方式

```
[Alice 本地]                      [云端]
  ↓                                 ↓
决策模型分析                    只接收纯文本立场
  ↓                                 ↓
生成初步观点                    LLM 生成摘要
  ↓                                 ↓
人类审核确认  → 提交纯文本 →   收敛判定
  ↓                                 ↓
本地不泄露                      差异化追问
```

### 2. 多轮收敛的过程

- **第一轮**: 收集初始立场
- **摘要**: LLM 分析共识和分歧
- **判定**: 
  - 收敛度高 → `awaiting_decision`（Owner 拍板）
  - 收敛度低 → 生成追问 → 第二轮
- **重复**: 最多 6 轮

### 3. 隔离性的实现

- 个人决策模型：留在本地
- 提交内容：只有人类确认的文本
- 可见范围：只能看到平台摘要
- 最终决策：由 Owner 拍板
