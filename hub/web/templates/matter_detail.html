给参与人的 AI 助手：直接读这块板子（不用开浏览器）

参与人把他的令牌交给助手后，助手用自己那边的 HTTP 客户端或 MCP 客户端直接读就行， 不需要浏览器自动化（不要让它去点网页、截图）。把下面几条命令复制给它 （hdt_xxx 换成参与人自己的令牌）： 

# 1) 板子现在什么情况（最快、最省上下文）
curl -s --compressed /api/items/{{ matter.id }}/board_summary -H "Authorization: Bearer hdt_xxx"

# 2) 最新一份总结文档全文（纯 markdown，可以直接转给本人看）
curl -s --compressed /api/items/{{ matter.id }}/board_summary/document -H "Authorization: Bearer hdt_xxx"

# 3) 这块板攒了哪几版总结文档
curl -s --compressed /api/items/{{ matter.id }}/board_summary/documents -H "Authorization: Bearer hdt_xxx"

# 4) 要看原文再拉留言（别一上来拉全板）
curl -s --compressed "/api/items/{{ matter.id }}/messages?limit=50" -H "Authorization: Bearer hdt_xxx"

# 5) 有没有人点名向我提问
curl -s --compressed /api/questions -H "Authorization: Bearer hdt_xxx"
