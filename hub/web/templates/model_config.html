{# --------------------------------------------------------- 诚实边界 #}
这个页面不管什么
  • 请求超时 仍是服务端常量（LLM_REQUEST_TIMEOUT_SECONDS，当前 {{ effective.timeout_seconds }} 秒），本页不暴露。
  • 轮次上限、任务超时、限流阈值 各有自己的服务端配置，不在本页。
  • Key 以明文存放在本机数据库：调用时必须用原文发出 Bearer，可逆存储是客观需要，与既有的 .env 同机同目录、同属一个暴露等级。补偿是页面只回显掩码、审计只记「改没改」、日志从不记 Key。
  • 改配置会改变后续所有调用的模型与账单归属，因此每次保存都写一条 llm_config_updated 审计（可在「审计查询」按事件类型筛到）。
