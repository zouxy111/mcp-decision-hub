可拉取的 Skill 包

两个 skill，各一行命令装进你自己的 agent。装完落在 ~/.workbuddy/skills/<名字>/SKILL.md —— 也可以直接把下面的 SKILL.md 拷到手边的目录里。

一次装两个（推荐）

一个负责把 hub 接上，一个负责产出决策模型。这两个是配套的：接上之后，衡量「值不值得用」的第一件事就是让 agent 产出一份决策模型。

mkdir -p ~/.workbuddy/skills \ && curl -fsSL https://hub.tdp-demo.work/static/skills/skills.tar.gz \ | tar xz -C ~/.workbuddy/skills
  • 复制的是一行。 上面显示成三行只是为了好读，续行符 \ 是语法的一部分；点「复制」拿到的是一行等价命令。
  • 等价写法 curl -fsSL https://hub.tdp-demo.work/static/skills/install.sh | sh。
  • 可覆盖 SKILLS_DIR 改目标目录，默认 ~/.workbuddy/skills。
  • 不依赖任何东西：不用仓库、不用 Node、不用管理员权限，脚本本身只做 mkdir、下载、解包三件事。

关于这些文件
  • 全部是纯文本。 每个 skill 只有一个 SKILL.md，没有脚本、没有依赖、没有二进制。装之前可以先在浏览器里读一遍再决定。
  • 解包即用。 包内顶层就是 skill 目录名，配合 tar xz -C ~/.workbuddy/skills 直接落位，不需要再手动改名或移动。
  • 可卸载。 rm -rf ~/.workbuddy/skills/<名字> 就是全部卸载动作 —— 它们没有往别处写任何东西。
  • 与部署同步更新。 这一页与 server 上跑的是同一批文件；server 上的 skill 更新后，重跑一次安装命令即可。
